# Retro OpenMW

An OpenMW port of [Retro Skyrim](https://www.nexusmods.com/skyrimspecialedition/mods/38464)
by **monobelisk**: an ENB post-process that makes the game look like it runs on
retro hardware, with chunky pixels, a limited colour palette, ordered dithering
and a CRT screen.

Requires **OpenMW 0.49 or newer** (post-processing shaders).

## What's included

| Shader | File | Effects |
| --- | --- | --- |
| **Retro** | `data/shaders/retro.omwfx` | Pixelation, palette colour mapping or posterize, ordered (Bayer) dithering, outline contrast |
| **Retro CRT** | `data/shaders/retro_crt.omwfx` | Screen curve, scanlines, horizontal scanline blur, RGB pixel mask, vignette |

You can use each one on its own. For the full Retro Skyrim look, enable both, with
**Retro** before **Retro CRT**.

### Palettes

Pick a palette in the **Retro** shader's settings:

| # | Palette | Source |
| --- | --- | --- |
| 0 | Posterize (no palette) | Retro Skyrim's "posterize" technique; uses *Colours per channel* |
| 1 | PAL (Retro Skyrim default) | Retro Skyrim, copied exactly |
| 2 | Deluxe Paint | Retro Skyrim's Deluxe Paint add-on, copied exactly |
| 3–18 | Game Boy, Virtual Boy, Monochrome, CGA (cyan / magenta), CGA / EGA 16, EGA / Master System 64, Teletext / BBC Micro, ZX Spectrum, Commodore 64, MSX, Apple II, Macintosh II, PICO-8, Amstrad CPC, NES, 8-bit RGB (3-3-2) | Generated by `tools/make_palettes.py` with the same colour matching as Retro Skyrim's LUTs |

## Installation

1. Put this folder somewhere permanent.
2. Add its `data` folder to `openmw.cfg`. With the OpenMW launcher: **Data Directories → Append**.
   By hand:
   ```
   data="/path/to/retro-openmw/data"
   ```
3. Turn on post-processing with the launcher's *Post Processing* option, or add this to
   `settings.cfg`:
   ```
   [Post Processing]
   enabled = true
   chain = retro,retro_crt
   ```
4. In game, press **F2** to open the shader menu. From there you can enable or disable,
   reorder and tune both shaders. OpenMW saves your changes.

## Settings

**Retro**

| Setting | Default | Notes |
| --- | --- | --- |
| Palette | PAL | See the table above |
| Colours per channel | 5 | Posterize only |
| Pixel size | 5 | Size of a retro pixel in screen pixels at 1080p; scales with resolution |
| Dither strength / power | 1.0 / 1.0 | |
| Invert edge brightness | off | Partially inverts the brightness of object outlines |

**Retro CRT**

| Setting | Default |
| --- | --- |
| Pixel size | 5 (**keep it equal to Retro's**, so scanlines and the pixel mask line up with the retro pixels) |
| Screen curve | 0.03 |
| Vignette strength | 1.0 |
| Scanline strength | 0.59 |
| Scanline blur samples / strength | 2 / 0.35 |
| CRT pixel mask strength | 0.1 |

The defaults are the values in Retro Skyrim's preset `enbeffectpostpass.fx.ini`.

## Differences from the ENB version

The shader code is a line-by-line port of Retro Skyrim's `enbeffectpostpass.fx`. Where
it differs:

- **Two shaders instead of one.** OpenMW only gives a shader the previous shader's output.
  So when Retro runs first, the CRT's horizontal blur works on the retro image instead
  of the untouched scene. The difference is subtle.
- **Depth.** The outline contrast used Skyrim's non-linear depth buffer. Here it is
  computed from OpenMW's linear depth and converted with Skyrim's near plane, so the
  outlines respond the same way.
- **Even pixel blocks.** The middle screen pixel of each retro pixel falls exactly on a
  rounding tie. In the ENB, float noise decided that tie, which gave uneven blocks. Here
  ties are always rounded the same way, so every block is the same size.
- **Palette storage.** Palettes live in one 3D texture, `data/textures/retro/palettes.dds`,
  instead of `lut.png`. OpenMW 0.49 and later versions orient 2D PNGs differently, but
  never flip 3D textures, so the lookup works in every version.
- The ENB read each palette's colour count from the LUT's alpha channel, but it changed
  the dither amount by about one part in a million, so a fixed value is used.

## Performance

Like the original, the Retro shader averages 252 samples per screen pixel to get each
retro pixel's colour. That is fine on a dedicated GPU but can be heavy on integrated
graphics at high resolutions.

## Rebuilding the palettes

`tools/make_palettes.py` rebuilds `palettes.dds` from the palette list in the script. It
copies Retro Skyrim's own palettes (PAL and Deluxe Paint) from the existing `palettes.dds`,
so keep those two first in the list. It needs Python 3 with `numpy`:

```
python3 tools/make_palettes.py
```

To add a palette:

1. Append it to `PALETTES` in the script.
2. Add a matching entry to the `uPalette` choice list in `retro.omwfx`.
3. Update `PALETTE_COUNT` in `retro.omwfx`.
